MOVIE TICKET RESERVATION SYSTEM
INTRODUCTION:
The Movie Ticket Reservation System is a Python based project developed using Thinter.it provides a graphical interface for a movie ticket booking.
FEATURES:
User Panel
Admin Panel
User Authentication
Movie Ticket Reservation
TECHNOLOGIES USED
Python
Tkinter
SQLite Database
PROJECT FILES
main.py
admin_panel.py
user_panel.py
auth.py
database.py
models.py
config.py
utils.py
HOW TO RUN
1.Install Python on your computer.
2.Open the project folder in the terminal.
3.Run the command:
python main.py
CONCLUSION
This project helps users manger movie ticket reservations through a simple graphical interface.
